# ListenTrace M13 — Round 2 原型对比包说明与决策指南

## 1. 对比包目标与原则

在 **Round 1** 原型反馈中，以下 8 项核心架构与设计决策已被正式**冻结（Frozen）**：
1. **产品个性**：Warm Professional Learning Desk（温润专业的研读桌面）
2. **双轨外壳（Hybrid Shell）**：管理界面保留侧边栏；沉浸研读界面弱化全局框架；侧边栏支持折叠与宽度调整。
3. **流程导航归属**：Stage 1–5 属于会话内局部向导导航，非全局常驻导航。
4. **信息密度**：Spacious Learning（开阔通透的学习间距）。
5. **纸质底板质感**：按场景适配柔和哑光纸质底色（`#FAF8F4`）。
6. **视听播放舞台**：全工作区深色暗光沉浸模式（Focus Mode）。
7. **动作语法**：每屏默认严格单一 Primary 按钮；破坏性动作（Danger）视觉隔离；不可用状态附带原因提示。
8. **卡片深度与结构**：采用 Prototype A 级深度，已明确批准“Cue-as-Card”卡片模型。

**Round 2 对比包仅聚焦于回答剩余的最后两个视觉决策问题**，保持排版、卡片深度、间距、文案完全恒定：
- **问题 A：色彩性格方案对比（Options B / C / D / E）**
- **问题 B：场景状态语言分级强度（Contextual State-Language）**

## 3. 场景状态语言分级强度设计

为避免全天候“徽章云”轰炸，原型在 3 个典型场景下演示了差异化状态表达策略：

```
[场景 1: 资料库 / 历史]  ──>  丰富状态 (Rich Scan)  ──>  胶囊徽章、多维标签、进度百分比 (便于全局扫描与过滤)
[场景 2: 播放 / 聚焦视听]  ──>  极简状态 (Quiet Focus) ──>  纯色左侧指示条、微波形发光 (零杂乱徽章，注意力 100% 聚焦听音)
[场景 3: 引导研读 / 回忆]  ──>  平衡状态 (Balanced)   ──>  步骤指示器、Diff 柔和高亮、归因分类标签 (辅助认知构建)
```

1. **场景 1：素材资料库与全局历史（高辨识度扫描）**
   - 学习者需要一览全局，快速判断哪些素材处于活跃精听会话、哪些需关注难点句、哪些已掌握。
   - 状态表达：采用 `Stage 3 (48%)`、`⚠️ 3 个未掌握`、`✓ 已完成` 等彩色胶囊徽章，提升扫描效率。
2. **场景 2：播放与聚焦视听（低噪沉浸视听）**
   - 学习者在连续听音与快速选句时，最需要消除视觉杂音。
   - 状态表达：杜绝满屏徽章！仅通过 **空间聚焦、纯色左侧强调条、高亮文字** 传达播放中状态；循环尾部补偿（200ms Grace）收拢至状态指示，不打扰视线。
3. **场景 3：引导研读与回忆重构（平衡辅助认知）**
   - 学习者在进行 Stage 3 听写归因与 Stage 5 回忆复述时，需要清晰的证据提示。
   - 状态表达：提供五阶段 Stepper、逐词 Diff 纸面高亮、听音障碍分类标签（连音/生词/语法/语速/声学），辅助认知反思。
